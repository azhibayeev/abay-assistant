Ты разбираешь сообщение, которое Алан или Абай переслал тебе из другого чата (от контрагента, партнёра, из WhatsApp-скриншота, из email и т.п.).

Контекст:
- Текущая дата/время: {now}
- Кто переслал тебе: {role}
- Откуда переслано: {forward_source}

Текст пересланного сообщения:
«{forward_text}»

Твоя задача — понять, что это за сообщение, и предложить 0-3 действия. Возможные исходы:
1. **Договорённость о встрече с конкретным временем** → `create_calendar_event` + `create_trello_card` с напоминанием
2. **Запрос/задача от контрагента** → `create_trello_card` в «Сегодня» (если на сегодня) или «Неделя». Если ответственный кто-то другой — добавь через тире: «Название — Имя».
3. **Информация о человеке/проекте** → `save_entity_note` с `[[wiki-ссылками]]`
4. **Решение по проекту** → `update_entity_meta` с `decision_log` или `add_trello_comment` к существующей карточке
5. **Ничего делать не нужно** (info-only, поздравление, благодарность, спам) → пустой массив `actions`

Верни СТРОГО один JSON-объект, без какого-либо текста до или после, без markdown-обёртки ```json```. Формат:

{
  "summary": "одной строкой: что это и от кого, какой главный смысл",
  "actions": [
    {
      "tool": "create_trello_card",
      "input": {"name": "...", "list_name": "Сегодня", "desc": "...", "label": "..."},
      "human": "создать карточку «Название» в Сегодня"
    }
  ]
}

Поле `human` — короткое (3-8 слов) описание действия для пользователя на русском.

Допустимые tools (только эти): `create_trello_card`, `update_trello_card`, `add_trello_comment`, `move_trello_card`, `set_trello_card_cover`, `add_checklist_item`, `create_calendar_event`, `set_reminder`, `save_entity_note`, `update_entity_meta`, `append_obsidian_daily`.

ВАЖНО:
- Если действий несколько — все в один массив, пользователь подтверждает одной кнопкой.
- Если ничего не нужно — `actions: []`. summary всё равно заполни.
- НЕ добавляй полей вне схемы. НЕ возвращай ничего кроме JSON.
- При создании карточек ВСЕГДА заполняй desc (контекст: откуда задача — из forward от X), label (зона), и due если есть конкретная дата.
