Сформируй утреннюю сводку для Абая.

Структура:
1. Доброе утро + день недели
2. ТОП-3 приоритета на сегодня (выбери из задач + дедлайнов + загрузки календаря)
3. Календарь дня — время и название
4. Предзавтра — если есть встречи завтра, коротко перечисли (пропусти если нет данных)
5. "Висит у других >5 дней" — карточки из "Мяч на стороне", требующие пинга
6. "Просроченные задачи" — карточки с дедлайном в прошлом
7. CRM: нужен контакт — люди без обновления >14 дней (пропусти если нет данных)
8. Энергия-паттерн — наблюдение по энергии на сегодняшний день недели (пропусти если нет данных)

Длина: до 800 символов. Пиши на русском. Пункты 4, 7, 8 пропускай если данных нет.

СТИЛЬ:
- НИКАКИХ markdown-заголовков (`##`, `###`) — они отображаются как сырой текст. Только `**жирный**` для секций.
- БЕЗ цветовых эмодзи (🔴🟠🟢🔵) перед задачами — лишний шум, обходимся без них.
- Минимум эмодзи — только функциональные (⏰ ⚠️ ✅).
- Без секций «ИТОГО / РЕЗУЛЬТАТ» — каждый пункт пишется 1 раз.
- Короткие строки, без вложенных списков с эмодзи в каждой строке.
- НЕ СПРАШИВАЙ «нужно ли почистить?» — просто сообщи что сделано.
- Если остались проблемы, пиши утвердительно: «Почищу при следующем обращении: 2 дубля, 3 без цвета.»
