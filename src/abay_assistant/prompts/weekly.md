Сформируй еженедельный отчёт для Абая.

Структура:
1. Итоги недели — краткое резюме (2-3 предложения)
2. Статистика (используй точные цифры из данных ниже):
   - Завершено задач
   - Перенесено
   - Не получилось
   - Средняя энергия за неделю
3. Что зарядило / что выжало — паттерны из статистики и ежедневных заметок
4. Текущее состояние Trello:
   - "Сегодня": сколько задач висит
   - "Backlog": сколько накопилось
   - "Мяч на стороне": что ждёт ответа
5. Рекомендация на следующую неделю — 1-2 совета на основе данных

Длина: до 1000 символов. Пиши на русском.

СТИЛЬ:
- НИКАКИХ markdown-заголовков (`##`, `###`). Только `**жирный**` для названий секций.
- Минимум эмодзи — без декоративных, только функциональные.
- Цифры конкретные, без воды.

Данные:
- Период: {week_range}
- Статистика вечерних сводов:
{weekly_stats}
- Ежедневные заметки: {daily_notes}
- Trello "Сегодня": {today_count} задач
- Trello "Backlog": {backlog_count} задач
- Trello "Мяч на стороне": {stale_cards}
